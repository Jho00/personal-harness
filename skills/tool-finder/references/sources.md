# Источники подбора

Проверяй доступность заново при каждом подборе. Ни один каталог не гарантирует безопасность, актуальность или совместимость.

| Источник | Как использовать |
| --- | --- |
| https://www.skills.sh/ | Поиск по назначению и стеку; переход от карточки к исходному `SKILL.md` в репозитории. |
| https://skillsmp.com/ | Дополнительный поиск готовых скиллов; сравнение первоисточника с карточкой. |
| https://github.com/stars/Jho00/lists/tools | Пользовательский список инструментов. Открой список, затем подходящие репозитории и конкретные файлы. |
| https://github.com/stars/Jho00/lists/ai | Пользовательский список AI-репозиториев. Ищи внутри подходящих репозиториев готовые промпты, скиллы и роли, не только приложения. |
| https://github.com/msitarzewski/agency-agents | Подбор роли по обязанности и результату; прочитай конкретный файл роли. Это материал для роли, а не уже доступный запущенный агент. |

Можно искать через встроенный поиск сайта, подключённый GitHub или веб-поиск `site:...` по обезличенной теме. Не выдумывай API каталога и не требуй установки CLI для чтения. В списках GitHub следуй доступной пагинации; если просмотрена только часть, укажи охват. Обычный список всех starred-репозиториев не заменяет состав именованного списка.

Для промптов ищи реальные файлы и разделы в репозиториях из списков. Если предложен твой собственный текст на основе находки, явно назови его адаптацией и сохрани ссылку на источник. Не приписывай адаптацию автору оригинала.

Если список требует входа или не открывается, отрази это в отчёте; не утверждай, что он пуст. Недоступность одного источника не блокирует остальные. Непроверенные сниппеты поиска оставляй кандидатами, а не готовыми рекомендациями к запуску.
