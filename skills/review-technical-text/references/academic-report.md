# Отчёт предпроверки документа

Верни только отчёт в Markdown, начиная с заголовка выше. Сохрани разделы 0–8. Для каждой подтверждённой проблемы выбери одну основную категорию и приоритет. Сводка считает проблемы в разделах 1–6, а список исправлений отсылает к ним. Словарь источников и вопросы, требующие проверки, указывай отдельно от числа подтверждённых проблем.

Если для раздела нет замечаний, укажи это короткой строкой. Если проверка неприменима или возможна только частично, укажи её статус и причину. В таблицах опирайся на места и формулировки, которые можно найти в предоставленном тексте.
