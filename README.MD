# Personal Harness

Скиллы, сценарии и роли для агентных клиентов.

[Подробная документация и порядок установки](docs/README.md).

| Скилл | Краткое описание | Команда установки |
| --- | --- | --- |
| [tool-finder](docs/tool-finder.md) | Подбор готовых инструментов под задачу и общий локальный журнал применения. | `npx skills add Jho00/personal-harness --skill tool-finder --copy` |
| [review-technical-text](docs/review-technical-text.md) | Ревью русскоязычных технических и научных текстов с приоритетами и предложениями правок. | `npx skills add Jho00/personal-harness --skill review-technical-text --copy` |
