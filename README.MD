# Personal Harness

Скиллы, сценарии и роли для агентных клиентов.

## Промпты

Каталог `prompts/` предназначен для готовых промптов для корректного использования в рамках харнесса. Пока он пуст и содержит только `.gitkeep`.

## Скиллы

| Скилл | Назначение |
| --- | --- |
| [tool-finder](skills/tool-finder/SKILL.md) | Подбор готовых промптов, скиллов, агентов и инструментов под длительную задачу; общий локальный журнал применения и разбор повторяющихся сценариев. |
| [review-technical-text](skills/review-technical-text/SKILL.md) | Ревью русскоязычных технических и научных текстов. Возвращает замечания с приоритетом, местом и предложением по исправлению. |

Общий порядок ревью находится в `SKILL.md`. Для научных текстов и разделов с обоснованием технического выбора скилл подключает соответствующие инструкции из `references/`. Для полного академического документа он собирает сводку по шести категориям, подробные замечания и вопросы для проверки по первоисточникам. [Формат отчёта](skills/review-technical-text/references/academic-report.md)

## Установка из репозитория

Когда скилл появится в ветке по умолчанию на GitHub, запусти команду из проекта, в котором хочешь его использовать. Для команды понадобятся Node.js и `npx`.

```bash
npx skills add Jho00/personal-harness --skill review-technical-text --copy
```

Выбери клиент в установщике, например Codex или Claude Code. Команда скопирует скилл вместе со справками в каталог этого клиента.

## Запуск

В Codex выбери `$review-technical-text` и приложи документ или вставь фрагмент. Укажи, если нужна проверка по требованиям конкретного издания.

```text
$review-technical-text Проверь раздел с выбором СУБД. Верни замечания по приоритету.
```

## ToolFinder

После описания длительной задачи вызови `$tool-finder`. Он проверяет skills.sh, SkillsMP, списки GitHub Jho00 Tools и AI, а также agency-agents. Найденные компоненты не устанавливаются автоматически: установка требует согласования.

```text
Мне нужно подготовить технический отчёт по архитектуре сервиса.
$tool-finder Подбери готовые средства для исследования, написания и проверки.
```

После merge скилл можно отдельно установить той же утилитой (команда приведена для самостоятельного запуска, сейчас ничего не устанавливается):

```bash
npx skills add Jho00/personal-harness --skill tool-finder --copy
```

Общий журнал по умолчанию хранится вне Git в `~/.local/share/personal-harness/tool-finder/`. Каталог переопределяется через `TOOL_FINDER_LOG_DIR` или `--log-dir`. Скрипт требует Python 3.9+ без сторонних библиотек. Для просмотра: `python3 /path/to/tool-finder/scripts/usage_log.py summary`. Подробности записи, ограничения облачных сред и переноса между компьютерами: [правила журнала](skills/tool-finder/references/journal.md). Он учитывает только наблюдавшиеся или подтверждённые применения, а не автоматически следит за всеми чатами.

Для периодического разбора попроси: `$tool-finder Разбери журнал и предложи повторяющиеся сценарии`. Частота рекомендаций отделена от частоты использования.

Проверки: `python3 -m unittest discover -s evals/tool-finder -v`; [сценарии оценки](evals/tool-finder/scenarios.md).
