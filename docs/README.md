# Документация Personal Harness

[Вернуться к каталогу](../README.MD)

## Скиллы

- [ToolFinder](tool-finder.md): подбор готовых средств, пример вызова и общий журнал использования.
- [Ревью технического текста](review-technical-text.md): область проверки, формат результата и пример вызова.

Страницы в `docs/` предназначены для пользователя. Инструкции для агента находятся в `skills/<name>/SKILL.md`, а необходимые скиллу справки и скрипты остаются рядом с ним. Поэтому отдельная установка скилла не требует копирования `docs/`.

## Установка из репозитория

Команды в [корневом каталоге](../README.MD) устанавливают выбранный скилл из ветки по умолчанию. Запусти нужную команду из проекта, в котором хочешь его использовать. Для установщика понадобятся Node.js и `npx`.

Выбери клиент в установщике, например Codex или Claude Code. Флаг `--copy` копирует скилл вместе со справками и другими файлами его каталога. Дополнительные зависимости отдельных скиллов указаны на их страницах.

Приведённые команды ничего не устанавливают сами по себе. Если установку выполняет агент, он должен предварительно согласовать с пользователем установку скиллов, плагинов, инструментов и зависимостей, в том числе для проверки.

## Промпты

Каталог [`prompts/`](../prompts/) предназначен для готовых промптов для корректного использования в рамках харнесса. Пока он пуст и содержит только `.gitkeep`.
