# Ревью технического текста

[Документация](README.md) · [Каталог и команда установки](../README.MD)

Скилл `review-technical-text` проверяет русскоязычные технические и научные тексты: ВКР, статьи, инженерные отчёты и описания архитектуры. Он возвращает замечания с приоритетом, местом и предложением по исправлению. Правки в исходник вносятся только по отдельному запросу.

## Как вызвать

После [установки](README.md) в Codex выбери `$review-technical-text` и приложи документ или вставь фрагмент. Укажи, если нужна проверка по требованиям конкретного издания.

```text
$review-technical-text Проверь раздел с выбором СУБД. Верни замечания по приоритету.
```

## Что получится

Общий порядок ревью находится в [SKILL.md](../skills/review-technical-text/SKILL.md). Для научных текстов скилл подключает [академическую предпроверку](../skills/review-technical-text/references/academic-review.md), а для разделов с обоснованием технического выбора — [проверку решений](../skills/review-technical-text/references/decision-review.md).

Для полного академического документа результат включает сводку по шести категориям, подробные замечания, приоритетный список исправлений и вопросы для проверки по первоисточникам. [Формат отчёта](../skills/review-technical-text/references/academic-report.md).

Для фрагмента или обычного технического ревью отчёт короче: итог и границы проверки, затем замечания по приоритету. Если данных недостаточно, скилл отделяет подтверждённые ошибки от утверждений, которые ещё требуют проверки.
