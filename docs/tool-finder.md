# ToolFinder

[Документация](README.md) · [Каталог и команда установки](../README.MD)

Скилл `tool-finder` подбирает готовые промпты, скиллы, роли агентов и инструменты под длительную задачу. Он проверяет skills.sh, SkillsMP, списки GitHub Jho00 Tools и AI, а также agency-agents. Найденные компоненты не устанавливаются автоматически: установка требует согласования.

## Как вызвать

После [установки](README.md) опиши длительную задачу и вызови `$tool-finder`:

```text
Мне нужно подготовить технический отчёт по архитектуре сервиса.
$tool-finder Подбери готовые средства для исследования, написания и проверки.
```

В ответе будет небольшой набор компонентов с исходными ссылками, назначением на конкретных этапах, ограничениями и способом вызова. Если часть источников недоступна, скилл обозначит границы проверки.

## Общий журнал

Журнал по умолчанию хранится вне Git в `~/.local/share/personal-harness/tool-finder/`. Каталог переопределяется через `TOOL_FINDER_LOG_DIR` или `--log-dir`. Помощник журнала требует уже установленный Python 3.9+ без сторонних библиотек. Если Python отсутствует, его установку нужно согласовать.

Для просмотра замени `/path/to/tool-finder` на путь к установленному скиллу:

```bash
python3 /path/to/tool-finder/scripts/usage_log.py summary
```

Подробности записи, расположения журнала, ограничения облачных сред и переноса между компьютерами: [правила журнала](../skills/tool-finder/references/journal.md). Он учитывает только наблюдавшиеся или подтверждённые применения и не следит автоматически за всеми чатами. Между компьютерами журнал автоматически не синхронизируется.

Для периодического разбора попроси:

```text
$tool-finder Разбери журнал и предложи повторяющиеся сценарии.
```

Частота рекомендаций отделена от частоты использования. Предложение нового сценария само по себе не приводит к его созданию или установке.
